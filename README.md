# HinglishSense: Sentiment Analysis for Code-Mixed Hindi-English Text

A real-world NLP project that classifies sentiment (positive / negative / neutral)
in Hinglish text — the code-mixed Hindi-English language used across Indian social media.

**Dataset:** SemEval-2020 Task 9 — SentiMix (Hinglish)  
**Models:**
- Baseline: TF-IDF + Logistic Regression
- Transformer: XLM-RoBERTa (fine-tuned)
